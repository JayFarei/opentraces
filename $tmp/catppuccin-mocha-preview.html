Cards & accents

Primary (Blue)

Structure, links, and call-to-action. Use on Base for high-contrast navigation and titles.

Secondary (Pink)

Soft emphasis, tags, and secondary headings without competing with Blue.

Tertiary (Teal)

Eyebrows, success-adjacent UI, and light decorative labels.

Attention (Yellow)

Warnings and “look here” moments. Pair sparingly with Surface cards.

# catppuccin mocha · sample config
background = "#1E1E2E"
foreground = "#CDD6F4"
cursor     = "#F5E0DC"

def theme_preview(name="mocha"):
    palette = {
        "blue": "#89B4FA",
        "pink": "#F5C2E7",
        "teal": "#94E2D5",
    }
    return { "name": name, "colors": palette, "ok": True }
