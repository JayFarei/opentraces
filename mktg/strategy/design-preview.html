features ────────────────────────────────

passive capture

Reads existing agent log files from disk. No hooks, no daemons, no runtime overhead.

three security tiers

Danger mode for OSS. Automated screening for most. Manual review for sensitive code.

training-first schema

Outcome signals, sub-agent hierarchy, per-step tokens. Designed for SFT and RL.

huggingface native

Publishes JSONL to HF Hub. Loadable via datasets.load_dataset(). No proprietary lock-in.

multi-agent support

Claude Code, Codex, Gemini CLI, Cursor, Cline. One schema, many agents.

agent trace attribution

Embeds code attribution at file:line granularity. Bridges trajectory and code output.

contributor dashboard

Your personal analytics. Cost, cache efficiency, tool usage, success rates.

agent-native cli

Every command outputs structured JSON with next_steps. Built for agents to drive.

zero config

One pip install. One command. Auto-discovers sessions, auto-detects agents.

use cases ──────────────────────────────
sft

Fine-tune on real workflows

Filter to outcome.success == true. Extract tool_call/tool_result pairs. Real data, not synthetic.

rl / rlhf

Reward from outcomes

The outcome field signals success or failure. Build process and outcome reward models from trajectory pairs.

research

Study agent behavior

How do developers use agents? Which tools are overused? Where are tokens wasted? The data answers.

orchestration

Learn sub-agent patterns

parent_step hierarchy captures explore/plan/execute delegation strategies for training.

attribution

Trace code to reasoning

Agent Trace says which lines are AI. opentraces says which conversation produced them.

ecosystems

Filter by dependency

"All sessions using Stripe." Dependencies extracted and tagged. Domain-specific datasets.

logo construction
glyph: interlocking knot, two woven strands
concept: two traces interlocking, data flowing through each other. the weave = open exchange, contribution, interoperability
strand 1: matches text color (dark on light, light on dark). represents the developer's code/work
strand 2: always accent orange (#F97316 dark, #C2410C light). represents the agent trace
wordmark: set in JetBrains Mono 400. the dot in ".ai" is always accent color
min size: 16px for glyph-only, 14px font for wordmark
clear space: 1x glyph width on all sides
