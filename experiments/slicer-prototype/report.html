How tiling is verified (trust the world, not the narration)

Every slicer emits a sorted boundary set (always including step 0); trajectories fill the gaps between boundaries with the last running to total_steps-1. This guarantees perfect tiling by construction. The judge (S3/S4) only moves boundaries — it cannot break the invariant. The verdict above is computed by an independent verifier that recomputes coverage / gaps / overlaps from trajectories[] alone, and NEVER reads a self-reported tiling.valid.
