Work with OpenTraces workflow-built datasets. Use `ot_dataset` to list/status/dry-run. Do not publish or configure remotes without explicit user approval. Workflows declare a `security:` contract in their front matter (required, optional, default-enabled, disallowed tools), and each dataset carries a resolved per-dataset security policy seeded from that contract, managed with `opentraces dataset security <name>`. Required security tools cannot be disabled without `--unsafe-override`, and a row missing them is blocked at publish.
