How It Works

Three steps to contribution

From install to insights in under five minutes. Your traces stay local until you explicitly push.

1

Install the CLI

A single pip install gives you the opentraces command. Works alongside your existing agent workflow, no configuration required.

$ pip install opentraces
2

Configure your security tier

Choose how aggressively traces are scrubbed before upload. From fast regex redaction to full manual review, you control the pipeline.

$ opentraces config --tier 2
3

Push to HuggingFace

Traces land in your personal HF dataset. Browse them on the Hub, see your contributor dashboard, share with the community.

$ opentraces push
Security First

You control what leaves your machine

Three security tiers let you balance speed and thoroughness. Every trace is processed locally before upload.

Tier 1 · Fast

Regex Auto-Redact

Pattern-based scrubbing for known secret formats. Fast, deterministic, ideal for open-source projects with no sensitive data.

  • API keys, tokens, passwords caught by pattern
  • Sub-second processing time
  • Configurable pattern library
Tier 2 · Recommended

Heuristic Classifier

ML-based detection with escalation for uncertain cases. The default for most users, balancing thoroughness with speed.

  • Context-aware secret detection
  • Uncertain items flagged for review
  • Catches non-obvious sensitive data
Tier 3 · Maximum

Full Human Review

Every trace opened in a web UI for manual inspection before upload. For sensitive codebases where nothing should slip through.

  • Web-based review interface
  • Line-by-line redaction controls
  • Audit log of all review decisions
Nothing uploads without your explicit action. Traces are processed and reviewed locally. You push when ready.

For ML Teams

Real developer workflows, not synthetic benchmarks

Structured trace data from real coding agent sessions, with outcome signals, sub-agent hierarchy, and code attribution.

Outcome signals for RL / reward modeling

Every trace includes success/failure signals linked to specific actions. Train reward models on real developer outcomes, not proxied quality scores.

Sub-agent hierarchy for orchestration research

Traces capture full parent-child relationships between agents. Study how delegation patterns affect task completion.

Per-step token counts for efficiency analysis

Every step records input, output, and cache token counts. Measure the real cost of agent strategies at scale.

Code attribution linking conversations to output

Each code snippet is linked to the conversation turn that produced it. Trace the full lineage from prompt to committed code.

# Load traces from HuggingFace Hub
from datasets import load_dataset
ds = load_dataset(
  "opentraces/community-traces"
)
# Filter for successful outcomes
successes = ds.filter(
  lambda x: x["outcome"]["success"]
)
# Extract tool call sequences
tool_chains = [
  [s["tool"] for s in t["steps"]]
  for t in successes
]

Standards

Built on open standards

opentraces works with the ecosystem, not against it. Import, export, and interoperate.

Standard Relationship Status
Agent Trace Spec 10+ backers We embed attribution blocks from the spec. Full compatibility with Cursor and other backers. Implemented
ATIF / Harbor Own schema with ATIF export adapter. Traces can be converted to ATIF format for interoperability. Export Ready
ADP Same adapter pattern with richer output. Extends ADP concepts with outcome signals and attribution. Compatible
OpenTelemetry Compatible via OTel export. Traces can be pushed to any OTel collector for observability workflows. Export Ready
DataClaw Import adapter with migration path. Move existing DataClaw traces into the opentraces format. In Progress
Get Started

Start contributing in five minutes

Five commands from zero to your first published trace.

1

Install the CLI

Works with Python 3.9+. No additional dependencies required.

$ pip install opentraces
2

Authenticate with HuggingFace

Links your HF token so traces land in your personal dataset space.

$ opentraces auth
3

Discover local traces

Scans for agent trace files from supported coding agents (Claude Code, Cursor, Copilot, and more).

$ opentraces discover
4

Review before upload

Opens a local web UI where you can inspect, redact, and approve each trace before it goes anywhere.

$ opentraces review --web
5

Push to HuggingFace Hub

Approved traces are uploaded to your HF dataset. They appear on the Hub immediately, ready for the community.

$ opentraces push
